# TastyCart

TastyCart is a **food ordering web application** built using **HTML, CSS, JavaScript, Bootstrap, and JSON Server**.
It allows users to browse food items, add them to a cart, mark favourites, and place orders with order history stored in LocalStorage.

---

## 🚀 Features

* 🍽️ Dynamic food menu fetched from API
* 🔍 Search food items
* 🥗 Veg / Non-Veg filtering
* ❤️ Add or remove favourites
* 🛒 Add to cart with quantity control
* 📦 Place order with order summary modal
* 📜 Order history with dropdown view
* 💾 Data persistence using LocalStorage
* 📱 Responsive UI using Bootstrap

---

## 🛠️ Tech Stack

**Frontend**

* HTML5
* CSS3
* JavaScript (ES6)

**UI Framework**

* Bootstrap 5

**Backend (Mock API)**

* JSON Server

**Storage**

* LocalStorage
